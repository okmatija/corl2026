# assets/

Drop trip inputs here: work itinerary, conference schedule, flight options, links/screenshots of places you want to see, notes.
Claude reads these and updates `data/trip.js`.

**This repo is public** (GitHub Pages). Anything committed here is visible to anyone.
Put sensitive documents (booking confirmations, passport info, addresses, work-internal schedules) in
`assets/private/` instead - that folder is git-ignored, so Claude can read it locally but it never gets pushed.
